# 图片分类标注工具

将图片分配到不同的子工件类别，支持一张图片属于多个类别。

## 功能

- 浏览文件夹中的所有图片
- 为每张图片选择所属的子工件类别（支持多选）
- 保存分类结果为JSON文件
- 键盘快捷键支持

## 使用方法

```bash
python image_classifier.py -i <图片文件夹> -o <输出JSON文件> -c <类别1> <类别2> ...
```

### 参数说明

- `-i, --input`: 输入图片文件夹（必需）
- `-o, --output`: 输出JSON文件路径（必需）
- `-c, --categories`: 子工件类别列表，可指定多个（必需）

### 示例

```bash
# 分类车门门环图片到三个子工件
python image_classifier.py \
    -i E:/work/车门门环拼接/images \
    -o E:/work/车门门环拼接/classification.json \
    -c 子工件A 子工件B 子工件C
```

## 操作说明

### 界面操作

1. **复选框选择**: 勾选当前图片所属的子工件类别（可多选）
2. **上一张/下一张按钮**: 切换图片
3. **保存并退出**: 保存分类结果并关闭程序
4. **不保存退出**: 放弃更改并关闭程序

### 键盘快捷键

- `←` / `→`: 上一张/下一张图片
- `S`: 保存并退出
- `ESC`: 不保存退出

## 输出格式

JSON文件示例：

```json
{
  "子工件A": [
    "E:/work/车门门环拼接/images/img1.png",
    "E:/work/车门门环拼接/images/img2.png"
  ],
  "子工件B": [
    "E:/work/车门门环拼接/images/img2.png",
    "E:/work/车门门环拼接/images/img3.png"
  ],
  "子工件C": [
    "E:/work/车门门环拼接/images/img1.png"
  ],
  "未分类": [
    "E:/work/车门门环拼接/images/img4.png"
  ]
}
```

- 每个子工件字段包含属于该类的图片路径列表
- 同一张图片可以出现在多个子工件中
- 未被分类的图片会自动归入"未分类"字段

## 支持的图像格式

- PNG
- JPG / JPEG
- BMP
- TIF / TIFF
